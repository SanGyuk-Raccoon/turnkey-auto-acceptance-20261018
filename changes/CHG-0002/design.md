# 설계

외부 의존성 없이 ESM 파일 `src/salute.js`에 named export `salute(value)`를 둔다. 계약의 architectural binding인 `import { greet } from './greeter.js'`를 그대로 사용한다. 이 참조는 요구사항의 동작 의미와 구분하며 임의로 다른 경로로 대체하지 않는다.

`salute(value)`는 기존 named `greet`를 정확히 한 번 호출하고 반환값을 변경 없이 반환한다. 입력 변환, 정규화·`guest` 선택·인사말 형식 처리의 복제, 예외 가로채기는 하지 않는다. 따라서 비문자열 입력에서 `greet`의 `TypeError`가 그대로 전파된다.

구현 시 실제 저장소에서 고정 모듈이 없거나 이 설계로 계약을 충족할 수 없다는 구체적 근거가 확인되면 `needs_design`으로 중단하고 설계 보완 검토를 요청한다. `src/salute.js` 밖을 변경하거나 새 모듈을 만들거나 참조를 임의 대체하지 않는다. 현재 문서는 모듈 존재 여부나 검사 결과를 확인했다고 주장하지 않는다.

후속 실행은 한 작업으로 구성한다. 허용 파일 변경과 고정 9개 검사 확인 뒤 별도 자체 리뷰를 거쳐 PR 병합을 검토하고, 이후 별도의 최종 전체 검사와 목표 검증을 수행한다. 이는 아직 승인되거나 실행된 절차가 아니다.
