# 의도

공개 샘플을 검증하는 개발자에게 기존 `greet` 동작을 재사용하는 작은 `salute(value)` 진입점을 제공한다. 개발자는 이 named export를 통해 기존 결과와 오류를 그대로 받는다.

## 목표
- `src/salute.js`에 기존 `greet`를 정확히 한 번 재사용하는 named export `salute(value)`를 추가한다.
- 기존 검사 6개와 새 고정 검사 3개를 모두 skip 없이 통과시키는 것을 목표로 한다.

## 범위와 비목표
- 구현 변경은 `src/salute.js` 하나로 제한한다. 기존 소스, 검사, 설정, package/lockfile은 보존한다.
- 추가 기능이나 외부 의존성 도입, 네트워크 사용, 배포, `main` 브랜치 변경은 범위 밖이다.
- 고정된 기술 설계 참조를 임의로 대체하지 않는다. 실제 저장소에서 충족할 수 없으면 구체적 충돌 근거를 제시하고 설계 보완을 요청한다.
