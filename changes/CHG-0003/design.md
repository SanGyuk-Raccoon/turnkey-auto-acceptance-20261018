# 설계 보완안

기존 설계의 `import { greet } from './greeter.js'`는 대상 모듈이 없어 해석되지 않는다. 제공된 결함 기록에 따르면 기존 named `greet` export는 `src/greeting.js`에 있다. 요구사항을 유지하면서 설계의 architectural binding만 `import { greet } from './greeting.js'`로 수정할 것을 제안한다. 이는 검토용 문서 제안이며 아직 승인된 구현 지시가 아니다.

외부 의존성 없이 ESM 파일 `src/salute.js`에 named export `salute(value)`를 둔다. `salute(value)`는 기존 named `greet`를 정확히 한 번 호출하고 반환값을 변경 없이 반환한다. 입력 변환, 정규화·`guest` 선택·인사말 형식 처리의 복제, 예외 가로채기는 하지 않는다. 따라서 비문자열 입력에서 `greet`의 `TypeError`가 그대로 전파된다.

구현 변경은 `src/salute.js`에만 한정한다. 기존 소스, 검사, 의존성, 설정 및 package/lockfile은 보존한다. 이 경로 보완안으로도 계약을 충족할 수 없다는 구체적 근거가 확인되면 `needs_design`으로 중단하고 추가 설계 검토를 요청한다. 다른 파일을 변경하거나 새 모듈을 만들거나 참조를 임의 대체하지 않는다.

후속 실행은 한 작업으로 구성한다. 허용 파일 변경과 고정 9개 검사 확인 뒤 별도 자체 리뷰를 거쳐 PR 병합을 검토하고, 이후 별도의 최종 전체 검사와 목표 검증을 수행한다. 고정 검사 9개 통과와 skip 0개는 수용 기준이지 확인된 결과가 아니다. 이 후속 절차는 아직 승인되거나 실행되지 않았다.

개발자 검토와 문서 PR 병합, 새 계획 승인 및 명시적 재개 전에는 코드 구현을 진행하지 않는다.
