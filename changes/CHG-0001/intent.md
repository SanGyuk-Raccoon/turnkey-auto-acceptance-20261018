# 의도

공개 합성 샘플로 자동 개발 흐름을 시험하는 개발자가, 계획 승인 한 번 뒤 정확히 두 의존 작업 A→B의 순차 구현·별도 자체 리뷰·검사·병합·최종 목표 검증이 실제로 동작하는지 확인한다. 결과는 합의된 두 함수의 동작과 고정 Node.js 테스트 6개의 skip 없는 통과로 확인한다.

## 목표
- A에서 이름 정규화를 구현하고, A 병합 후 B에서 이를 재사용하는 인사말을 구현한다.
- 계획 승인 한 번 이후의 순차 진행, 작업별 자체 리뷰와 검사, 병합 및 별도 최종 목표 검증을 확인한다.

## 범위와 비목표
- 구현 변경은 공개 합성 샘플에 한정한다. A의 허용 경로는 `src/normalize-name.js`, B의 허용 경로는 `src/greeting.js` 각각 하나다.
- 고정 검사, `package.json`, lockfile은 변경하지 않는다.
- 외부 패키지 도입, 네트워크 사용, 배포, 계정 정보 사용, 실제 서비스 또는 Turnkey 원본 변경, 명시된 두 함수 외 추가 기능은 범위 밖이다.
